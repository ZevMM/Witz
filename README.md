This is a summer project I made to learn about investment portfolios and practice full-stack web development. I used React for front-end, Express/Node for back-end, and SQLite for the database. A lot of the menu bar buttons don't actually do anything, I recommend watching the walkthrough to get a sense of what features have been implemented. 
**The website is hosted on a free server which shuts down when inactive. Once the link is clicked, it takes about a minute to spin up** (the perfect amount of time to do a [mini crossword!](https://www.latimes.com/games/mini-crossword))
